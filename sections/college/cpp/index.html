01装好你的武器

三种方案，按你的设备情况选一个，十分钟搞定

C++ 是编译型语言：你写的 .cpp 是给人看的源码，必须经过「编译 → 链接」变成机器能跑的 .exe。所以你至少需要一个编译器，通常再配一个编辑器。

方案 A：在线编译器（零安装，最快上手）

如果你只是想先写几行试试，直接用网页版：搜「onlinegdb C++」「Compiler Explorer」「Programiz C++ online compiler」任意一个，左边写代码、点 Run 就能看结果。缺点是没法做大项目，交作业也不行。

方案 B：VS Code + MinGW-w64（推荐，轻量可控）

  1. 下载并安装 VS Code（微软官网，选 Windows 版）。
  2. 下载 MinGW-w64（推荐用 MSYS2 安装，或直接下 winlibs 的压缩包），把它里面的 bin 目录加到系统环境变量 PATH 里。
  3. 打开命令行，输入 g++ --version，能打印版本号就装好了。
  4. VS Code 里安装扩展：C/C++（Microsoft）和 Code Runner（可选）。
  5. 新建 hello.cpp，写完按 Ctrl + ` 打开终端，输入编译命令即可。
终端（命令行）
# 编译：把 hello.cpp 编译成 hello.exe
g++ hello.cpp -o hello

# 运行（Windows）
.\hello.exe
# 运行（macOS / Linux）
./hello

编译参数里最常用的几个：

参数作用建议
-o 名字指定输出的可执行文件名必加
-std=c++17使用 C++17 标准必加
-Wall -Wextra打开所有警告强烈建议，能提前发现大量 bug
-g带上调试信息，可断点调试调 bug 时加

懒人版命令（背下来） g++ main.cpp -o main -std=c++17 -Wall，写完这行，你的代码质量就比一半同学高。

方案 C：Visual Studio 2022 社区版（Windows 最省心）

安装时勾选「使用 C++ 的桌面开发」工作负载。新建「空项目」→ 添加 .cpp 文件 → 按 F5 直接运行，不用管命令行。代价是安装包 5GB 起、启动慢。如果你打算长期做 Windows 桌面程序或游戏，选它。

Dev-C++ 的取舍 很多高校机房装的是 Dev-C++。它上手快，但默认标准很老（C++98），且对中文编码支持差（中文注释可能变乱码）。能用，但建议早点换到 VS Code。如果被迫用 Dev-C++，在「工具 → 编译选项」里加上 -std=c++17，并在保存文件时选择 UTF-8 编码。

中文乱码怎么办

这是新手第一个高频问题。Windows 终端默认是 GBK 编码，而你的源文件通常是 UTF-8，于是中文输出变乱码。三个解法，任选其一：

  • 在终端先执行 chcp 65001 切到 UTF-8（临时有效）。
  • 编译时加参数 -fexec-charset=GBK（Windows 专用，兼容性最好）。
  • 入门阶段最简单：少用中文输出，用英文或拼音。等你能熟练调试了再折腾编码。

02第一个程序，逐行解剖

Hello World 不是仪式，是解剖学

hello.cpp
// 第 1 行：这是注释，// 后面的内容编译器完全无视
#include <iostream>   // 引入输入输出库，cout 就住在这里面

int main() {            // 程序的入口，操作系统从这里开始执行
    std::cout << "Hello, World!" << std::endl;   // 输出一行并换行
    return 0;           // 返回 0 表示「正常结束」
}

每一行的角色

部分解释
#include <iostream>预处理指令。把别人写好的「输入输出功能」搬进来。# 开头的行由预处理器处理，不是 C++ 语句，末尾不加分号。
int main()主函数。有且只有一个，程序从这里开始。int 表示它返回一个整数。
{ }花括号包住的东西叫「代码块」，是 main 的身体。
std::coutstd 是标准库的名字空间，cout 是「字符输出 + 控制台」。:: 读作「的」——标准库的 cout。
<<插入运算符，把右边的数据「塞进」输出流。可以连着塞：cout << "a" << 1 << "b";
std::endl换行并刷新缓冲区。等价于 "\n" 但会多一次刷新操作。
;语句结束符。忘加分号是新手第一号错误，编译器会报一堆莫名其妙的错。
return 0;把 0 交给操作系统，约定 0 = 成功。其实不写现代编译器也会自动加，但写上更清楚。
关于 using namespace std;

你可能在别人的代码里看过这一行，然后在后面直接写 cout 而不写 std::：

两种写法的对比
// 写法一：老老实实（推荐，尤其项目大了以后）
#include <iostream>
int main() {
    std::cout << "hi" << std::endl;
    return 0;
}

// 写法二：偷懒（考试和刷题常用）
#include <iostream>
using namespace std;   // 把整个标准库的「公共前缀」省略掉
int main() {
    cout << "hi" << endl;
    return 0;
}
为什么说写法二有风险 using namespace std; 会把标准库里的几千个名字全部倒进当前作用域。一旦你自己定义了同名的东西（比如函数 count、distance），就可能冲突报错。刷题、写小程序无所谓；等你要交正式项目、或进入公司写代码，请老实写 std::，或者只引入你要的：using std::cout;。

编译过程到底发生了什么

点一下 Run，背后其实走了四步。理解它，你以后看到报错就知道该看哪一类信息：

阶段做什么出错时你在终端看到
预处理展开 #include、替换 #define、去掉注释较少直接报错
编译把 C++ 变成汇编/目标代码，检查语法error: expected ';' 这类语法错误
汇编把汇编变成机器码 .o 文件很少出错
链接把你的代码和库函数拼在一起生成 .exeundefined reference to ...（找不到函数实现）
报错怎么读 GCC 的报错格式是 文件名:行号:列号: error: 具体原因。永远从第一条 error 开始改。第一条错误常会引起后面几十条连锁报错；改掉第一条再重新编译，可能瞬间全好了。

03变量与数据类型

把数据放进贴了标签的盒子里

变量就是一块内存，你给它起个名字。C++ 是静态强类型语言：用之前必须声明它装什么类型，而且类型一旦确定不能随便改。好处是编译器能帮你抓错，代价是啰嗦。

基本类型一览

类型典型大小能存什么示例
int4 字节整数，约 ±21 亿int age = 20;
long long8 字节超大整数，约 ±9.2×10¹⁸long long n = 1e18;
float4 字节小数，精度约 7 位有效数字float f = 3.14f;
double8 字节小数，精度约 15 位（默认用它）double pi = 3.14159;
char1 字节单个字符，用单引号char g = 'A';
bool1 字节true / falsebool ok = true;
std::string变长一串字符，用双引号std::string s = "abc";
main.cpp
#include <iostream>
#include <string>

int main() {
    int age = 20;                 // 整数
    double height = 1.75;         // 小数
    char grade = 'A';             // 单个字符，注意是单引号
    bool isStudent = true;        // 布尔值
    std::string name = "小明";     // 字符串，双引号

    std::cout << name << " " << age << " 岁" << std::endl;
    std::cout << "身高 " << height << " 米，等级 " << grade << std::endl;
    return 0;
}
三个必知陷阱 1. 单引号 vs 双引号：'A' 是一个字符（char），"A" 是字符串（string）。写混了会报错或行为诡异。
2. 未初始化的变量：int x; 然后直接 cout << x;，你得到的是一个随机垃圾值，不是 0。C++ 不会自动帮你清零！
3. 整数除法：7 / 2 的结果是 3 不是 3.5。整数除以整数，结果仍是整数（小数部分直接砍掉）。想得到 3.5 必须写成 7 / 2.0 或 7.0 / 2。

类型转换

不同类型混在一起运算时，编译器会「自动提升」到更宽的类型，这叫隐式转换：

类型转换示例
int a = 7, b = 2;
double r1 = a / b;                      // 结果是 3.0，不是 3.5！（先整数除，再转 double）
double r2 = (double)a / b;              // 结果是 3.5。显式转换（C 风格强制转换）
double r3 = static_cast<double>(a) / b; // 结果也是 3.5。C++ 推荐写法，更安全清晰

int i = 3.99;      // i 得到 3，不是 4——截断，不四舍五入
int j = (int)3.99; // 同上，显式说明意图更好
该选哪个类型 一般整数用 int；怕溢出（比如求和、阶乘）用 long long；小数统一用 double（float 精度太差，除非有性能或内存硬约束）。竞赛里有个经典事故：int 存 1 到 10 万的累加和会溢出（超过 21 亿），答案全错——这种时候必须 long long。

常量与 auto

main.cpp
const double PI = 3.14159265358979;  // 常量：赋值后不能再改，改了就编译报错
const int MAX_SIZE = 100;
// PI = 3.0;   // ← 如果取消注释，编译直接失败，这是好事，能防手误

auto x = 10;        // x 被推断为 int
auto y = 3.14;      // y 被推断为 double
auto z = 1 + 2.0;   // z 被推断为 double
// auto 不是「动态类型」，编译期就定死了，只是让你少写几个字

long long big = 1000000LL;  // 后缀 LL 明确表示 long long 字面量

命名规范（不用背，照做即可）

  • 只能由字母、数字、下划线组成，不能以数字开头（2sum ❌，sum2 ✅）。
  • 不能用关键字（int、for、class 等）。
  • 区分大小写：Age 和 age 是两个不同的变量。
  • 变量名用小驼峰 studentAge 或下划线 student_age，常量全大写 MAX_SIZE，见到 a、b、x1 这种名字就是欠揍。

04输入输出与格式控制

让程序开口说话、也学会听你说话

cin 的基本用法

input.cpp
#include <iostream>
#include <string>

int main() {
    std::string name;
    int age;

    std::cout << "请输入姓名和年龄：";
    std::cin >> name >> age;      // >> 是提取运算符，从输入流里「捞」数据

    std::cout << "你好，" << name << "，你今年 " << age << " 岁。" << std::endl;

    int a, b;
    std::cout << "输入两个整数（空格或回车分隔）：";
    std::cin >> a >> b;
    std::cout << "和 = " << a + b << "，差 = " << a - b << std::endl;
    return 0;
}
cin 的脾气 cin >> 会自动跳过空白（空格、Tab、回车），所以你输入 10 20 或 10 回车 20 效果一样。它读取失败时会停下，后面所有输入都不再有效——这是新手「程序卡住不动」的常见原因之一。

读一整行：getline

如果姓名中间有空格（比如 "Li Ming"），cin >> name 只会读到 "Li"，后面的 "Ming" 被留在缓冲区里，污染下一次输入。这时要用 getline：

getline 与经典坑
#include <iostream>
#include <string>

int main() {
    int id;
    std::string fullName;

    std::cout << "学号：";
    std::cin >> id;                 // 这里输了 1001 然后按回车
                                    // ← 回车符还留在输入缓冲区里！

    std::cout << "姓名：";
    std::getline(std::cin, fullName);   // 它会立刻读到那个残留的换行，结果是空字符串！

    // 正确做法：在两者之间吃掉那个换行
    // std::cin.ignore();            // 丢掉一个字符（就是换行）
    // 或更稳妥：
    // std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');

    std::cout << "[" << fullName << "]" << std::endl;
    return 0;
}

int main() {
    // 结构：for (初始化; 继续条件; 每轮结束后执行)

        std::cout << i << " ";

    // 倒着数
    for (int i = 5; i >= 1; i--) {
        std::cout << i << " ";
    }
    std::cout << "\n";              // 输出：5 4 3 2 1

    // 步长为 2
    for (int i = 0; i < 10; i += 2) {

    }
    std::cout << "\n";              // 输出：0 2 4 6 8

    for (int i = 1; i <= 9; i++) {

break 与 continue

break_continue.cpp
#include <iostream>

int main() {
    // break：立刻跳出整个循环
    for (int i = 1; i <= 100; i++) {
        if (i * i > 50) {
            std::cout << "第一个平方大于 50 的数是 " << i << "\n";
            break;                    // 找到就收工，不再继续
        }
    }

    // continue：跳过本轮剩余部分，直接进入下一轮
    for (int i = 1; i <= 10; i++) {
        if (i % 2 == 0) continue;     // 偶数跳过

}

进阶：基于范围的 for 循环（C++11 起）

遍历容器时，这种写法更简洁，也更不容易出下标错误：

range_for.cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> nums = {3, 1, 4, 1, 5, 9};

    for (int x : nums) {              // 复制一份，修改 x 不影响原容器
        std::cout << x << " ";
    }
    std::cout << "\n";

    for (int& x : nums) {             // 加 & 拿到引用，可以真正修改元素
        x *= 2;
    }
    // 现在 nums 变成 {6, 2, 8, 2, 10, 18}

    for (int i = 0; i < (int)nums.size(); i++) {   // 传统写法也一样能用
        std::cout << nums[i] << " ";
    }
    return 0;
}

注意 (int)nums.size() 里的强制转换：size() 返回的是无符号类型，直接和 int i 比较会有警告（-Wall 会提示 signed/unsigned 比较）。养成转换习惯，能少踩坑。

//  返回类型  函数名 (参数列表)

}

}

值传递 vs 引用传递 —— 这是理解 C++ 的分水岭

pass_by.cpp
#include <iostream>
#include <string>

// 值传递：把数据「复印」一份给函数，改不到原件
void tryChangeValue(int x) {
    x = 999;                       // 只改了副本，外面的变量毫发无损
}

// 引用传递：& 表示「这是原件的别名」，直接改原件
void changeByRef(int& x) {
    x = 999;                       // 外面的变量真的被改了
}

// 大型对象的推荐写法：const 引用
// 既避免复制（省内存省时间），又保证函数不会偷偷改动它
void printBig(const std::string& s) {
    std::cout << s << "（长度 " << s.length() << "）\n";
}

int main() {
    int a = 1, b = 1;
    tryChangeValue(a);
    changeByRef(b);
    std::cout << "a = " << a << ", b = " << b << "\n";   // a = 1, b = 999

    printBig("这是一段很长的文本，用引用传递避免复制");
    return 0;
}
参数传法的口诀 小类型（int、double、char、bool）→ 直接值传递，简单省事。
大对象（string、vector、自定义类）→ const 引用。
需要在函数里修改调用方的变量 → 非 const 引用。
只在必须处理「没有值」的情况才用指针参数。

// 默认参数：不传就用默认值。注意默认参数必须写在参数列表最右边
int power(int base, int exp = 2) {
    int r = 1;
    for (int i = 0; i < exp; i++) r *= base;
    return r;
}

// 函数重载：同名函数，靠参数类型/个数区分（C++ 特色）
int   maxOf(int a, int b)       { return a > b ? a : b; }
double maxOf(double a, double b){ return a > b ? a : b; }
double maxOf(double a, double b, double c) { return maxOf(maxOf(a, b), c); }

int main() {
    std::cout << power(5)    << "\n";   // 25，用了默认 exp=2
    std::cout << power(2, 10) << "\n";  // 1024

    std::cout << maxOf(3, 7)          << "\n";  // 自动选 int 版
    std::cout << maxOf(3.5, 7.2)      << "\n";  // 自动选 double 版
    std::cout << maxOf(1.0, 5.0, 3.0) << "\n";

}

    // 引用必须初始化，而且不能中途改绑
    // int& r;          // ❌ 编译错误：引用必须一开始就绑定
    // int& r2 = 5;     // ❌ 不能绑定到字面量（除非是 const 引用）

    const int& cr = 42;          // ✅ const 引用可以绑字面量，常用于函数参数
    return 0;
}

指针三件套：取地址、解引用、指针本身

pointer.cpp
#include <iostream>

int main() {
    int value = 42;

    int* p = &value;    // & 取地址：把 value 的门牌号交给 p
                        // int* 读作「指向 int 的指针」

    std::cout << "value 的值      = " << value << "\n";   // 42
    std::cout << "value 的地址    = " << &value << "\n";  // 类似 0x7ffd...
    std::cout << "p 里装的内容    = " << p << "\n";        // 同上，就是那个地址
    std::cout << "*p 解引用的结果 = " << *p << "\n";      // 42，* 表示「去这个地址取值」

    *p = 100;                     // 通过指针修改原变量
    std::cout << "现在 value = " << value << "\n";       // 100

    // 空指针：明确表示「不指向任何东西」
    int* np = nullptr;            // C++11 起用 nullptr，不要再用 NULL 或 0
    if (np == nullptr) {
        std::cout << "这是个空指针，不能解引用\n";
    }
    // std::cout << *np;          // ❌ 解引用空指针 = 程序崩溃

    return 0;
}

用一张表记住四个符号

符号名称怎么读示例
&取地址（在值前面）「……的地址」&value → 门牌号
*解引用（在指针前面）「去这个地址里取东西」*p → 42
int*指针类型（在类型后面）「指向 int 的指针」int* p;
int&引用类型（在类型后面）「int 的别名」int& r = value;
最常见的混淆 int* p = &value; 里的 * 只是在声明「p 是指针」，它不是解引用动作。
而 *p = 5; 里的 * 是真正的解引用。
同一个符号，两种身份，靠上下文区分——这就是指针难读的原因。建议写法：写成 int *p（星号贴近变量名）能更直观地理解成「*p 是一个 int」。

指针用在哪：动态内存

new_delete.cpp
#include <iostream>

int main() {
    // 在运行时申请一块内存（大小可以等到运行时才定）
    int n = 5;
    int* arr = new int[n];        // 申请 n 个 int

    for (int i = 0; i < n; i++) arr[i] = i * i;
    for (int i = 0; i < n; i++) std::cout << arr[i] << " ";
    std::cout << "\n";

    delete[] arr;                 // ⚠️ 必须手动释放！数组用 delete[]，单个对象用 delete
    arr = nullptr;                // 好习惯：释放后置空，防止误用野指针

    return 0;
}
两个致命错误 内存泄漏：只 new 不 delete，内存越用越少，长时间运行的程序会崩。
重复释放 / 释放后使用：delete 两次，或者释放后还去访问那块内存，属于未定义行为，可能随机崩溃。
但请注意：现代 C++ 已经基本不让你手写 new/delete 了。日常请用 std::vector 和智能指针（std::unique_ptr），它们会自动管理内存。这里讲是因为考试和面试会考，而且理解了它你才懂为什么 vector 好用。
进阶：指针与数组的暧昧关系（面试必问）

数组名在很多场合会「退化」成指向首元素的指针：

ptr_array.cpp
#include <iostream>

int main() {
    int a[5] = {10, 20, 30, 40, 50};
    int* p = a;              // 等价于 int* p = &a[0];

    std::cout << a[2]   << "\n";   // 30
    std::cout << *(a+2) << "\n";   // 30 —— 一模一样，这就是下标的真相
    std::cout << p[2]   << "\n";   // 30
    std::cout << *(p+2) << "\n";   // 30

    p++;                     // 指针可以移动，挪到下一个元素
    std::cout << *p << "\n"; // 20

    // 但数组名不能移动！
    // a++;                  // ❌ 编译错误

    // sizeof 的区别（常见考点）
    std::cout << sizeof(a) << "\n";   // 20（整个数组 5*4 字节）
    std::cout << sizeof(p) << "\n";   // 8（指针本身的大小）
    return 0;
}

所以 a[i] 和 *(a+i) 完全等价，编译器内部就是按后者处理的。把这个搞明白，指针就没那么吓人了。

11结构体 struct

把相关的数据打包成一个整体

数组要求所有元素类型相同。但一个学生有姓名（字符串）、学号（字符串）、成绩（小数），类型不同，数组装不下。结构体就是给这种场景准备的。

struct.cpp
#include <iostream>
#include <string>
#include <vector>

struct Student {
    std::string name;      // 这些叫「成员变量」
    std::string id;
    double score;
};

// 结构体也可以作为函数参数（推荐用 const 引用，避免复制）
void printStudent(const Student& s) {
    std::cout << s.id << "  " << s.name << "  " << s.score << "\n";
}

int main() {
    // 方式一：逐个赋值
    Student a;
    a.name = "小明";
    a.id = "2024001";
    a.score = 92.5;

    // 方式二：初始化列表（推荐，简洁）
    Student b = {"小红", "2024002", 88.0};

    // 方式三：C++11 起的统一初始化
    Student c{"小刚", "2024003", 76.5};

    printStudent(a);
    printStudent(b);
    printStudent(c);

    // 结构体能放进数组和 vector
    std::vector<Student> cls = {a, b, c};

    // 找最高分
    Student top = cls[0];
    double total = 0;
    for (const Student& s : cls) {
        total += s.score;
        if (s.score > top.score) top = s;
    }
    std::cout << "平均分 " << total / cls.size() << "\n";
    std::cout << "最高分是 " << top.name << "：" << top.score << "\n";

    return 0;
}
点号 vs 箭头 对结构体变量本身用点：a.name。
对指向结构体的指针用箭头：p->name（等价于 (*p).name）。
记忆：有星星就用箭头，没星星就用点。

结构体嵌套与排序

struct_sort.cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>   // sort 在这里

struct Point { int x, y; };

struct Student {
    std::string name;
    double score;
};

int main() {
    std::vector<Point> pts = {{1, 2}, {3, 4}, {0, 5}};
    int maxX = pts[0].x;
    for (const auto& p : pts) {
        if (p.x > maxX) maxX = p.x;
    }
    std::cout << "最大 x = " << maxX << "\n";

    // 按成绩从高到低排序
    std::vector<Student> cls = {
        {"A", 88.0}, {"B", 95.5}, {"C", 72.0}, {"D", 90.0}
    };

    std::sort(cls.begin(), cls.end(),
              [](const Student& a, const Student& b) {
                  return a.score > b.score;   // 大于号 = 降序
              });

    for (const auto& s : cls) {
        std::cout << s.name << " " << s.score << "\n";
    }
    return 0;
}
lambda 是什么 [](const Student& a, const Student& b) { return a.score > b.score; } 是 C++11 引入的匿名函数，专门给 sort 这类函数传「比较规则」用的。方括号里可以捕获外部变量。现在只要记住这个固定套路：想按哪个字段排，就把哪个字段拿来比较，升序用 <，降序用 >。

std::vector —— 会自己长大的数组

vector.cpp
#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    std::vector<int> v;              // 空的，不需要预先指定大小
    v.push_back(10);                 // 尾部追加
    v.push_back(20);
    v.push_back(30);

    std::cout << "元素个数：" << v.size() << "\n";     // 3
    std::cout << "第一个：" << v.front() << "\n";     // 10
    std::cout << "最后一个：" << v.back() << "\n";    // 30
    std::cout << "访问下标 1：" << v[1] << "\n";       // 20
    std::cout << "安全访问：" << v.at(1) << "\n";     // 20（越界会抛异常，更安全）

    v.pop_back();                    // 删掉最后一个 → {10, 20}

    // 直接用初始化列表构造
    std::vector<int> nums = {5, 2, 9, 1, 7};

    std::sort(nums.begin(), nums.end());            // 升序：1 2 5 7 9
    std::cout << "最小 " << nums.front() << "，最大 " << nums.back() << "\n";

    std::reverse(nums.begin(), nums.end());          // 反转
    for (int x : nums) std::cout << x << " ";
    std::cout << "\n";

    auto it = std::find(nums.begin(), nums.end(), 5);
    if (it != nums.end()) {
        std::cout << "找到了 5，下标 " << (it - nums.begin()) << "\n";
    } else {
        std::cout << "没找到\n";
    }

    std::cout << "是否为空：" << std::boolalpha << v.empty() << "\n";
    v.clear();                       // 清空
    std::cout << "清空后大小 " << v.size() << "\n";
    return 0;
}

追加v.push_back(x)尾部加元素，均摊 O(1)
删除尾部v.pop_back()O(1)
大小v.size()返回无符号数，比较时注意转换
判空v.empty()比 size() == 0 更语义化
访问v[i] / v.at(i)at 会做越界检查
排序std::sort(v.begin(), v.end())需要 <algorithm>
清空v.clear()size 变 0，容量不一定释放
vector 的两个坑 1. v[i] 不检查越界，和数组一样危险。要安全就用 v.at(i)。
2. push_back 可能让所有旧的引用/指针失效：vector 扩容时会搬家到新地址，之前保存的 int* p = &v[0]; 就变成野指针了。这是进阶话题，但值得先知道。

13类与对象

面向对象入门：把数据和操作绑在一起

结构体把数据打包了，但函数还在外面。类（class）更进一步：把数据和对数据的操作一起打包，并控制外部能不能碰。这是 C++ 从「C with class」变成一门大语言的地方。

class.cpp
#include <iostream>
#include <string>

class BankAccount {
private:                       // 私有：只有类内部的函数能访问
    std::string owner;
    double balance;

public:                        // 公有：外部可以调用
    // 构造函数：创建对象时自动执行，用来初始化
    BankAccount(const std::string& name, double initial)
        : owner(name), balance(initial) {}      // 初始化列表（推荐写法）

    void deposit(double amount) {
        if (amount <= 0) {
            std::cout << "金额必须为正\n";
            return;
        }
        balance += amount;
    }

    bool withdraw(double amount) {
        if (amount > balance) {
            std::cout << "余额不足\n";
            return false;
        }
        balance -= amount;
        return true;
    }

    double getBalance() const {          // const 表示「这个函数不会修改对象」
        return balance;
    }

    void show() const {
        std::cout << owner << " 的余额：" << balance << " 元\n";
    }
};

int main() {
    BankAccount acc("小明", 1000.0);     // 调用构造函数
    acc.show();                          // 小明 的余额：1000 元

    acc.deposit(500);
    acc.show();                          // 1500

    acc.withdraw(2000);                  // 余额不足
    acc.withdraw(300);
    acc.show();                          // 1200

    // acc.balance = 999999;             // ❌ 编译错误！私有成员外部无法访问
    return 0;
}

三个核心概念

概念含义为什么需要它
封装用 private 隐藏内部数据，只暴露安全的方法防止外部乱改数据，比如绕过余额检查直接改数字
构造 / 析构构造：对象诞生时初始化；析构：对象销毁时清理（~类名()）保证对象一出生就是合法的，资源能自动释放
const 成员函数函数名后加 const承诺不修改对象，让 const 对象也能调用它
struct 和 class 的唯一区别 在 C++ 里，struct 和 class 的唯一技术差别是默认访问权限：struct 默认 public，class 默认 private。
约定俗成的用法：纯粹装数据的用 struct（比如 Point、Student），有行为有封装的用 class。
进阶：构造函数重载与 this 指针
ctor.cpp
#include <iostream>
#include <string>

class Student {
private:
    std::string name;
    double score;

public:
    Student() : name("未知"), score(0) {}                    // 无参构造

    Student(const std::string& n) : name(n), score(0) {}      // 只给姓名

    Student(const std::string& n, double s) : name(n), score(s) {}

    // this 是「指向当前对象」的指针
    Student& setName(const std::string& name) {
        this->name = name;         // this->name 是成员，右边的 name 是参数
        return *this;              // 支持链式调用
    }

    void show() const {
        std::cout << name << " : " << score << "\n";
    }

    ~Student() {                   // 析构函数：对象生命周期结束时自动调用
        // 如果这里 new 过内存，就在这儿 delete
    }
};

int main() {
    Student a;                      // 调用无参构造
    Student b("小红");               // 调用单参数构造
    Student c("小刚", 95.0);         // 调用两参数构造

    a.show();
    b.show();
    c.show();

    c.setName("小刚同学").setName("刚哥");   // 链式调用，因为返回了 *this
    c.show();
    return 0;
}

三法则（Rule of Three）：如果你的类需要自定义析构函数，那么通常也需要自定义拷贝构造函数和拷贝赋值运算符——因为它们都在管同一份资源。这是 C++ 内存管理的深水区，初学知道有这回事就行，等你真的手写管理内存的类再回来看。

什么时候该用类 如果你只是想打包几个字段（坐标、学生信息），用 struct。
如果这些数据有「不变量」需要保护（余额不能为负、半径不能为负）、或者有多个相关的操作，用 class。
不要为了「面向对象」而面向对象——见过太多为了展示技术，把一个简单计算包装成五个类的代码。能一个函数解决的就别上类。

逻辑错误：编译器帮不了你

语法错误编译器会告诉你，但逻辑错误只能靠你自己（和调试器）。四个最经典的：

logic_bugs.cpp
// ① 循环差一次（Off-by-one）：想要 1 到 10，写了 < 10
for (int i = 1; i < 10; i++) { }        // 只跑到 9 ❌
for (int i = 1; i <= 10; i++) { }       // ✅

// ② 判断写成赋值
if (score = 60) { }                     // 永远为真 ❌
if (score == 60) { }                    // ✅

// ③ else if 顺序反了
if (score >= 60)  std::cout << "及格";
else if (score >= 90) std::cout << "优秀";   // 永远轮不到 ❌（顺序应从严格到宽松）

// ④ 整数除法丢精度
double avg = sum / count;               // 两个 int 相除，结果先截断 ❌
double avg = (double)sum / count;       // ✅

调试三件套

  1. 打印法（最土最有效）：在可疑位置插 std::cout << "DEBUG: i = " << i << "\n";，看变量在每一步到底是多少。用完记得删掉。
  2. 断点法（推荐）：VS Code 里装 C/C++ 扩展后按 F5 启动调试，在行号左边点一下加红点，程序会停在那里，鼠标悬停就能看到所有变量的当前值。比打印法高效十倍。
  3. 对分法定位：把可疑代码注释掉一半，看错误是否还在。在，说明问题在剩下那一半；不在，说明就在被注释的这半。二分几次就锁定了。
调试心态 崩溃不是失败，是编译器在帮你。真正危险的是能跑但结果错的程序——所以每次都要用你知道答案的例子测一遍（比如排序 3 个元素、判断 7 是不是素数）。这叫「单元测试」的雏形，好习惯从第一天开始养成。

17继承与多态

一个基类指针，调出子类自己的行为，差别全在 virtual 这一个词上

上一章那个 BankAccount 是孤零零一个类。真写程序的时候类往往成群：学生和研究生、圆和矩形、储蓄账户和信用卡账户。它们共享一部分东西，又各有各的细节。继承就是表达「是一种」的写法。

inherit.cpp
#include <iostream>
#include <string>

class Person {
protected:                      // 派生类能用，外部不能用
    std::string name;
    int age;

public:
    Person(const std::string& n, int a) : name(n), age(a) {}

    void introduce() const {
        std::cout << "我叫" << name << "，今年" << age << "岁\n";
    }
};

class Student : public Person {          // Student 是一种 Person
private:
    std::string major;

public:
    // 构造顺序：先基类，再自己的成员，最后才进函数体
    Student(const std::string& n, int a, const std::string& m)
        : Person(n, a), major(m) {}

    void study() const {
        std::cout << name << " 在学 " << major << "\n";
    }
};

int main() {
    Student s("小周", 19, "计算机");
    s.introduce();        // 从基类继承来的，直接能用
    s.study();
    return 0;
}

Student 里没写 introduce，但 s.introduce() 能调。因为每个 Student 对象内部先放了一个完整的 Person 部分。: Person(n, a), major(m) 这一行就是在初始化那块基类部分；不写它，编译器会去找 Person 的无参构造，找不到就报错。

基类里的成员派生类内部类外面
public能直接用能直接访问
protected能直接用不能
private不能直接用不能

私有成员并没有消失，只是派生类看不见。Person 的 name 若写成 private，Student::study 里写 name 就编译报错。想让派生类用、又不想让外面碰，用 protected。

没有 virtual，多态是句空话

下面这段，先猜输出，再读。

novirtual.cpp
#include <iostream>

class Animal {
public:
    void speak() const { std::cout << "动物叫了一声\n"; }
};

class Dog : public Animal {
public:
    void speak() const { std::cout << "汪\n"; }
};

int main() {
    Dog d;
    Animal* p = &d;      // 基类指针指向派生类对象，合法
    p->speak();          // 输出「动物叫了一声」
    d.speak();           // 输出「汪」
}

同一个对象，从两个口子调，出来两种结果。原因是 p 的静态类型是 Animal*，编译器在编译时就把 speak 绑死在 Animal::speak 上了。按「指针声明时是什么类型」决定调哪个函数，这叫静态绑定。

把基类那个函数前面加一个 virtual，行为立刻反过来。

virtual.cpp
#include <iostream>

class Animal {
public:
    virtual void speak() const { std::cout << "动物叫了一声\n"; }
    virtual ~Animal() = default;      // 有虚函数就把析构也写成虚的
};

class Dog : public Animal {
public:
    void speak() const override {     // override：我在覆盖基类的虚函数
        std::cout << "汪\n";
    }
};

int main() {
    Dog d;
    Animal* p = &d;
    p->speak();      // 现在输出「汪」
}

p->speak() 现在要到运行时才去查「这个对象真正是谁」，查到是 Dog，调 Dog::speak。这就是动态绑定，也是多态这两个字的本体。

override 不是装饰 不写 override 也能编译，因为 C++11 之前根本没这个关键字。但它值得写：一旦你手滑把 speak() const 写成 speak()（少了 const），基类那个虚函数就没有被覆盖；加了 override，编译器当场报错；不加，你就静悄悄造了一个新函数，运行时表现和你想的完全不一样，还查不出来。

纯虚函数与抽象类

有些基类本身没有意义。一个「形状」没有面积公式，只有具体的圆和矩形才有。这种只能当爹、不能拿来建对象的类，用纯虚函数写成抽象类。

shape.cpp
#include <iostream>

class Shape {
public:
    virtual double area() const = 0;            // 纯虚：只声明，不实现
    virtual const char* name() const = 0;
    virtual ~Shape() = default;
};

class Circle : public Shape {
    double r;
public:
    explicit Circle(double r) : r(r) {}
    double area() const override { return 3.14159 * r * r; }
    const char* name() const override { return "圆"; }
};

class Rect : public Shape {
    double w, h;
public:
    Rect(double w, double h) : w(w), h(h) {}
    double area() const override { return w * h; }
    const char* name() const override { return "矩形"; }
};

int main() {
    Circle c(2);
    Rect r(3, 4);

    Shape* list[2] = { &c, &r };        // 一个数组装两种形状
    double total = 0;
    for (int i = 0; i < 2; ++i) {
        std::cout << list[i]->name() << " 面积 " << list[i]->area() << "\n";
        total += list[i]->area();
    }
    std::cout << "合计 " << total << "\n";

    // Shape s;      // ❌ 编译错误：抽象类不能建对象
}

= 0 的意思是「这个函数我不实现，谁继承谁实现」。带纯虚函数的类不能创建对象，Shape s; 直接编译不过——编译器替你堵住了一个概念错误。

main 里那个循环是关键。数组装的是 Shape*，每个元素指向不同的派生类，一句 list[i]->area() 自动调到对应的实现，循环里完全不需要知道背后是圆还是矩形。以后要加三角形，只要新写一个类塞进去，循环一个字都不用改。这才是多态真正省下来的东西。

三个坑

基类析构函数不写 virtual Animal* p = new Dog; delete p; 只调 Animal 的析构函数，Dog 自己申请的东西全部泄漏。规矩很简单：类里只要有一个虚函数，析构函数一律写成 virtual ~类名() = default;。
对象切片 Animal a = d; 把 Dog 对象按值拷进一个 Animal，多出来的部分被切掉，之后 a 怎么调都叫不出「汪」。要用多态，就用指针或引用传对象，别按值传。
在构造函数里调虚函数 构造基类部分的时候，派生类部分还没建好，虚函数表指向的仍是基类版本。这个坑不常踩，踩了极难查。构造函数里只做初始化，别调可能需要多态的成员函数。

上机作业

这一章的代码在页内解释器里跑不了（它不支持继承和虚函数），必须上真实编译器，命令见第 1 章。

  2. 加一个 Triangle 类继承 Shape，main 里把三种形状一起算总面积。

该不该用继承 拿「A 是一种 B」这句话试一下。读着别扭的（「汽车是一种引擎」），八成该用组合——把一个对象当成员放进去，而不是继承。继承是最强的耦合，用错了以后改起来很疼。

18模板与泛型

同一段逻辑换个类型就要重写一遍，这件事可以交给编译器做

求最大值，int 写一版，double 写一版，string 再写一版，逻辑一个字不差，只有类型不同。C++ 的办法是把这个「类型」本身变成参数。

tpl.cpp
#include <iostream>
#include <string>

template <typename T>
T myMax(T a, T b) {
    return a > b ? a : b;
}

int main() {
    std::cout << myMax(3, 7) << "\n";                        // T 推成 int，输出 7
    std::cout << myMax(2.5, 1.5) << "\n";                    // T 推成 double，输出 2.5
    std::cout << myMax<std::string>("abc", "abd") << "\n";   // 输出 abd
}

template 那一行声明了一个类型参数 T，函数体里把它当类型用。调用时编译器从实参推出 T 是什么，然后现场生成一份真函数，这个过程叫实例化。myMax(3, 7) 和 myMax(2.5, 1.5) 编译完是两个完全独立的函数，运行时没有任何「猜类型」的开销。

typename 还是 class <typename T> 和 <class T> 在模板里完全等价。老代码里 class 多，新代码一般写 typename，因为 T 不一定是类，也可能是 int。
两个参数类型不一致会推不出来 myMax(3, 4.5) 编译报错，因为 T 同时被推成 int 和 double。三种解法：写成 myMax<double>(3, 4.5) 显式指定；或者先把 3 存进一个 double 变量；或者干脆写两个类型参数 template <typename T, typename U>。

类模板

类型参数也能挂在类上。下面这个 Box 什么都能装。

box.cpp
#include <iostream>
#include <string>

template <typename T>
class Box {
private:
    T value;
public:
    explicit Box(const T& v) : value(v) {}
    T get() const { return value; }
    void set(const T& v) { value = v; }
};

int main() {
    Box<int> a(10);
    Box<std::string> b("hello");

    std::cout << a.get() << " " << b.get() << "\n";   // 10 hello
    a.set(99);
    std::cout << a.get() << "\n";                    // 99
}

用的时候必须写尖括号里的类型。Box<int> 和 Box<std::string> 是两个不同的类，各有一份代码。这一点和函数模板不同：函数的类型能推，类的不能推（C++17 之后部分场景可以，初学别依赖）。

自己写一个能用的栈

第 12 章用 vector 的时候你觉得挺方便。下面是同一个东西的骨架，二十来行，什么类型都能装。

stack.cpp
#include <iostream>
#include <vector>
#include <string>

template <typename T>
class Stack {
private:
    std::vector<T> data;
public:
    void push(const T& v) { data.push_back(v); }
    void pop() { if (!data.empty()) data.pop_back(); }
    T& top() { return data.back(); }
    const T& top() const { return data.back(); }
    bool empty() const { return data.empty(); }
    size_t size() const { return data.size(); }
};

int main() {
    Stack<int> si;
    si.push(1); si.push(2); si.push(3);
    std::cout << si.top() << " 共 " << si.size() << " 个\n";   // 3 共 3 个

    Stack<std::string> ss;
    ss.push("甲"); ss.push("乙");
    std::cout << ss.top() << "\n";                          // 乙
}

它没写析构函数、没管扩容，因为 vector 已经在内部管好了。标准库里的 vector<int>、map<string,int>、pair<int,double> 全都是这样造出来的——你从第 12 章起就在用类模板，只是那时候不知道尖括号是什么意思。

19资源管理与异常

new 出来的内存归谁管，什么时候还——这一章讲 C++ 最容易出事故的地方

前面所有变量都开在栈上，函数一返回自动没了。这一章讲堆：手动申请、手动归还的那块内存。程序崩得最莫名其妙的地方，基本都在这儿。

heap.cpp
#include <iostream>

int main() {
    int* p = new int(5);         // 堆上要一块 int，初值 5
    std::cout << *p << "\n";     // 5
    *p = 8;
    std::cout << *p << "\n";     // 8
    delete p;                    // 还回去

    int* arr = new int[10];      // 数组要写方括号
    for (int i = 0; i < 10; ++i) arr[i] = i * i;
    std::cout << arr[9] << "\n";  // 81
    delete[] arr;                // 也必须用 delete[]
}

new 和 delete 必须配对，数组的 delete[] 少了方括号就是未定义行为。编译器不会提醒你，程序可能当天没事、下周换台机器就崩。

两种典型事故

leak.cpp
void bad() {
    int* p = new int[100];
    if (true) return;      // 提前返回，下面这行永远走不到
    delete[] p;
}

int main() {
    for (int i = 0; i < 1000000; ++i) bad();   // 每次漏 400 字节
}

这个程序跑一会儿内存就上去了。泄漏不会立刻崩，只是慢慢吃光内存，所以最难发现。长跑的服务程序挂掉，一半是这个原因。

dangling.cpp
int* p = new int(5);
delete p;
*p = 10;              // ❌ 已经还回去了还写
std::cout << *p;      // ❌ 同上

这叫悬空指针。它有时候能跑、有时候崩、有时候悄悄改坏别的变量——三种表现取决于那块内存当时被谁拿走了。这类 bug 靠加打印很难找，因为它不报错。

异常：把出错的地方和处理的地方分开

除数为零、文件打不开、用户输入了字母，函数知道自己干不了，但它不知道该怎么办（提示重输？写日志退出？）。抛出去，让上层决定。

exc.cpp
#include <iostream>
#include <stdexcept>

double divide(double a, double b) {
    if (b == 0) throw std::runtime_error("除数不能为 0");
    return a / b;
}

int main() {
    try {
        std::cout << divide(10, 2) << "\n";   // 5
        std::cout << divide(10, 0) << "\n";   // 抛异常，跳到 catch
        std::cout << "这行不会执行\n";
    }
    catch (const std::exception& e) {
        std::cout << "出错：" << e.what() << "\n";
    }
    std::cout << "程序继续往下走\n";
}
方式写法适合
返回错误码bool ok = f();错误很常见、调用方必须处理
抛异常throw std::runtime_error("...")错误少见、需要层层往上传递
断言 / 直接崩assert()程序员的逻辑错误，本来就不该发生
没人接的异常会终止程序 异常一路往上抛，路上没有 catch 就调 std::terminate，程序直接死，连栈都不给你看。所以 main 里应该有 try-catch；写多线程的话，每个线程入口也要有。

RAII：让析构函数替你还内存

new 之后中途 throw，delete 一样执行不到，还是泄漏。C++ 的标准解法不是到处写 try-catch，而是把「申请」放进构造函数、把「释放」放进析构函数。对象一销毁，析构一定执行，不管你从哪条路出去的。

raii.cpp
#include <iostream>

class IntArray {
private:
    int* data;
    size_t n;
public:
    explicit IntArray(size_t size) : data(new int[size]()), n(size) {}
    ~IntArray() { delete[] data; }              // 一定执行

    IntArray(const IntArray&) = delete;              // 禁止拷贝，防止两个对象管同一份内存
    IntArray& operator=(const IntArray&) = delete;

    int& operator[](size_t i) { return data[i]; }
    size_t size() const { return n; }
};

int main() {
    IntArray a(5);
    for (size_t i = 0; i < a.size(); ++i) a[i] = static_cast<int>(i * i);
    std::cout << a[4] << "\n";     // 16
}   // 离开作用域，~IntArray 自动 delete[]

这个模式叫 RAII（资源获取即初始化），是 C++ 里最该养成的工程习惯。文件句柄、互斥锁、数据库连接、socket，全都这么管。它的价值不在省事，在于「不可能忘记」——忘记的那条路根本不存在。

智能指针：这个类不用你自己写

手写 RAII 容易漏，比如拷贝构造忘了写就是双重释放。标准库已经把这件事做完了。

smart.cpp
#include <iostream>
#include <memory>

class Shape {
public:
    virtual double area() const = 0;
    virtual ~Shape() = default;
};

class Circle : public Shape {
    double r;
public:
    explicit Circle(double r) : r(r) {}
    double area() const override { return 3.14159 * r * r; }
};

int main() {
    std::unique_ptr<Circle> c = std::make_unique<Circle>(2.0);
    std::cout << c->area() << "\n";     // 12.5664
}   // c 离开作用域，对象自动 delete

unique_ptr 独占所有权，不能拷贝但能 std::move 转交；shared_ptr 是引用计数，几处共用一个对象，计数归零才释放。初学的规矩很简单：默认 unique_ptr，确实需要共享再上 shared_ptr。

shared_ptr 唯一的坑 两个对象互相持有对方的 shared_ptr（A 里有 B，B 里有 A），计数永远不归零，两个对象永远不释放。这叫循环引用，解法是把其中一边改成 weak_ptr。除此之外，智能指针比裸指针安全得多。

声明和定义是两件事

函数可以只写「长什么样」，不写「怎么算」：

声明
double average(const std::vector<Student>& list);   // 只有原型，没有函数体

这叫函数声明。有了它，别的文件就能调用这个函数，编译器知道参数和返回值对不对；函数体在哪儿，链接的时候再去找。编译和链接是两步，编译通过不代表能跑起来。

阶段谁做出错信息长什么样
编译每个 .cpp 单独变成 .o语法错、类型错、找不到声明：error: ...
链接把所有 .o 拼成 exe找得到声明但找不到实现：undefined reference to ...

undefined reference 第一次见很懵，它 99% 是这三种情况：忘了把某个 .cpp 放进编译命令；声明和定义的参数对不上（声明是 int，定义写成 double）；把函数定义写在头文件里又没加 inline。

类模板装数据

src/repository.h
#pragma once
#include <vector>
#include <memory>
#include <string>
#include <algorithm>
#include <functional>

template <typename T>
class Repository {
private:
    std::vector<std::unique_ptr<T>> items;

public:
    void add(std::unique_ptr<T> item) { items.push_back(std::move(item)); }

    T* findById(const std::string& id) const {
        for (const auto& p : items)
            if (p->getId() == id) return p.get();
        return nullptr;
    }

    bool removeById(const std::string& id) {
        for (auto it = items.begin(); it != items.end(); ++it) {
            if ((*it)->getId() == id) { items.erase(it); return true; }
        }
        return false;
    }

    void sortBy(std::function<bool(const T&, const T&)> cmp) {
        std::sort(items.begin(), items.end(),
                  [&](const std::unique_ptr<T>& a, const std::unique_ptr<T>& b) {
                      return cmp(*a, *b);
                  });
    }

    void printAll() const {
        for (const auto& p : items) p->print();
    }
    size_t size() const { return items.size(); }
};

为什么存 unique_ptr<T> 而不是 T？因为 Person 是抽象类，没法按值存；存指针才有多态。为什么用智能指针而不是裸指针？这样删元素、清空容器的时候不用记着 delete。

#include <iostream>
#include <limits>

int readInt(const std::string& prompt) {
    int v;
    while (true) {
        std::cout << prompt;
        if (std::cin >> v) return v;
        std::cin.clear();                                  // 清掉错误状态
        std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
        std::cout << "输入的不是整数，请重新输入\n";
    }
}
