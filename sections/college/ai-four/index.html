关于 AI 的四件事

入学之前想到几点，写下来，你什么时候看都行。

01CONTEXT

它已经在你每天的决定里

它已经进了日常，用不用其实没得选，能选的只剩下怎么用。

两年前它还只是个新鲜东西，现在会议纪要、作业、修图、问路，甚至看病之前要不要挂号，很多人都会先问它一句。中国互联网络信息中心今年九月的报告说，国内生成式 AI 的用户已经过了七亿，普及率过半，其中七成多用在问答上，三成多用来写总结、纪要和 PPT。

以前几次技术变革换掉的主要是力气，这一次换掉的是判断。读片、写代码、起草文书，这些原本都是人的活，现在它做得不差。而且来得快，人还没学会怎么用它，它已经换过两代了。

这些事离你也不远。早上醒来第一眼看什么，是算法排好的；出门走哪条路，是导航定的；写一段话，第一句往往就是模型替你接的。这些都不算毛病，人确实省了力气。我只是想让你留意一件事：同样都是点一下，有些活是你拿它办的，有些活是它替你办的，看起来一样，过几年差别就出来了。

02CLASSROOM

上课怎么用

上课之前先知道自己要听什么，同样坐两小时，听到的东西不一样。

上课之前，建议你花十五分钟做一件事。把这一章的小节标题抄给它，让它回答一个问题：这一章学完，应该能够回答哪五个问题。然后把这五个问题抄在笔记本第一页，不要记在手机上，上课翻手机容易分心。带着它们进教室，你听课的位置就变了，从抄板书的人变成核对的人。

课上不必什么都记，记三种就够，用三个符号：

  • △ 是它没讲到的，通常是老师自己的经历、本地的情况、他踩过的坑。
  • × 是跟它讲的不一样的，这些往往是考点。
  • ？ 是没听懂的，一句话记下来，别当场纠缠，纠缠下去后面十分钟就漏掉了。
不要做

另外三件事不要做：

  • 不抄板书全文。抄下来也不会看第二遍，黑板上的东西书上都有。
  • 不全程录音。录完不会重听，多数时候只是给自己一个安心的理由。
  • 不在课上打开它。课上查一次，整节课的线索就断了。

下课当天，先把那些问号处理掉，不要过夜，过了这个时间连自己写的问题都看不懂。然后再让它就这一章出十道题考你，先自己写答案，再看它的。顺序要是反了，先看了它的答法，这个练习就没什么用了，因为看着眼熟和真会做，在感觉上几乎分不出来。十道题能自己答对七道，这一章就算过；答不对的，回教材找那一段。

写作业有一条规矩，建议你守住：关掉 AI，自己写初稿。初稿写得差没关系，但必须有。初稿写完了再让它进来，让它做三件事：

  • 指出论证最弱的地方，并且给出三个反驳。
  • 指出哪一句话没说清楚，哪一句是废话。
  • 把里面的事实、数字、法条，标成确定、不确定、不知道。

按它的意见改的时候，改的是你的判断，不是照抄它的措辞。照抄会让文章变得不像你写的，而且你自己不知道为什么那么改。

核对

法条、司法解释、标准号、数字，一律回原文核。它编得非常像，条号、款项、措辞都对，唯独内容不是那一条，这种情况我遇到不止一次。核对的地方是国家法律法规数据库和标准原文。标准分两处查：国家标准全文公开系统（openstd.samr.gov.cn）收强制性国家标准和推荐性国家标准，免费在线看，也能下载；食品安全国家标准不在这个系统里，要到食品安全国家标准数据检索平台查，环境标准在生态环境部网站。

03LAYERS

别停在问答

问答是最低的一层，往上还有两道坎：先让它替你干活，再自己训一个小模型。

把 AI 当搜索框用，只用了它一小半。它还能读文件、写代码、操作软件，也能把几件事接成一条流程，比如让手机拍一批现场照片，自动归类，生成记录表，再归档。这些已经不是问答，是让工具替你动手。

中间有几层台阶，一层比一层难：

  • 会问，是指能要什么、给谁看、有什么限制，都说清楚。这一层三个月足够。
  • 会串，是指能把几件事接成一条流程。做法不玄：把一件事从头到尾的步骤写下来，看哪几步只是搬运和整理，那几步交出去，剩下的自己做。
  • 会训，是指自己能准备数据、训练模型、测试它，知道它在什么情况下会出错。

大多数人停在第一层，因为第一层已经够用了。往上走的那一步，靠的不是多学几个工具，是把一件真事从头做到尾。

工具也不必只用聊天窗口。装一个能读文件的，建一个课程文件夹，把教材 PDF、课件、法条汇编放进去，提问的时候直接把文件给它，比空口问强得多。

常用的指令固定三个就够了：

  • 一个用来提问，把背景、要求、限制一次说全。
  • 一个用来审稿，让它只挑毛病，不许重写。
  • 一个用来出题，指定章节和题量，答案另附。

用熟三个比收藏三十个有用。

想系统补一补，三门免费的就够。吴恩达的《AI for Everyone》，六个小时，讲的是它能干什么、不能干什么。李沐的《动手学深度学习》，中文版在 zh.d2l.ai，每章配代码，能直接跑。Kaggle 的免费微课，一节几十分钟，边做边学。

责任

还有一样东西它替不了你，就是签字。鉴定意见上签名的是你，出了问题追的也是你的责任，所以它为什么这样判断、会在哪里出错，你得知道。

04FIELD

结合专业，找能做的题目

题目不用往外找，就在你们的课表和实验室里。

你们的核心课程里有“人工智能导论”，不是选修，和刑法学、刑事侦查学、犯罪现场勘查排在一起。所以你不必另外去找 AI 的入口，它就在课表上，当作主课来上就行。学校还有环境资源与食品药品犯罪侦查实验室、食药环快检实训室、毒品分析检验实验室，这几个地方以后都用得上。

化学是你手上最现成的东西。你有基础，也有条件，只是还没有真正拿它做过事。化学训练给人的是答案已知时快速求解，现在更需要的是答案未知时能提出问题，这两件事不冲突，前者还是后者的底子——看不懂谱图，它给你百分之九十九的把握，你也不知道该不该信。

C 和 Python 之间没有原则性的区别，同一套算法在两门语言里是同一套逻辑，不存在选错这回事。区别在别处：C 有课，一个学期学到能写链表、能读写文件、能看懂指针，就够了；Python 没课，得自己排时间，每周三个小时，它才是以后的主力。C 的地盘收窄了，但没有消失，现场的快检设备、光谱仪、执法记录仪、无人机，里面的固件基本都是 C，机器人更是这样。

你要是更喜欢动手，就顺着 C 往单片机走。现场那些便携设备，说白了是一个单片机加一个传感器：单片机按时读数、存下来、发出去，判断留给后面的程序。入门用 ESP32，一块板子几十块钱，自带无线，插上 USB 就能烧程序。第一个项目别做小车，做一个小采集盒：接一个气体或土壤传感器，每分钟记一次数，存进 SD 卡，同时通过串口送到电脑，用 Python 画成曲线。这一套走通，你就知道数据是怎么从现场到你桌上的，光谱仪不过是换了一个更精细的传感器。再往上用能跑 Linux 的板子，比如树莓派，接摄像头跑现成的识别模型，无人机上挂的多半是这一类。

入门跟这几样走就行：

  • 太极创客的免费教程，中文，配视频，Arduino 和物联网两块都讲得细。
  • ESP32 官方文档加 Arduino IDE 自带的示例，先把 Blink 和 WiFi 两个例子跑通，剩下的都是在这两个上面改。
  • 学校要是用 STM32，正点原子的教程和视频对得上课本，跟着做不会跑偏。

光谱与模型

如果只挑一个题目开始，我建议从光谱入手。食药环案件的物证主要是食品、药品、土壤、水，检验大量依靠近红外和拉曼，而光谱数据本身就是一组数字，是数字就能交给模型，这是化学和 AI 之间最短的一条路。现成的数据也有人整理好了，Open-Nirs-Datasets 里有药品一千六百多条、肉类一百多条、土壤三千七百多条，RamanBench 有七十四个数据集、三十二万条光谱，配套的 Python 包装上就能用。

小练

第一学期做三件事就够了：

  1. 跑通 sklearn 里的 PLS 回归。这是化学计量学的入门例子，几十条数据，二十行代码。
  2. 把三聚氰胺那份数据画成曲线，看掺假和没掺假的谱差在哪一段。这一步不涉及算法，全是看图，但看图比跑模型更有用。
  3. 复现一篇论文。今年《分析化学》第一期有一篇，福建江夏学院的团队，做到 99.75% 的准确率，不是清华北大，也不是中科院。

这条线上要用的东西都是现成的：

  • 方法在 scikit-learn 的文档里，PLSRegression 那个例子直接能跑；预处理三件套（SNV、一阶导数、Savitzky-Golay 平滑）也都有现成函数，各跑一遍就知道分别管什么。
  • 数据不用自己找，前面那两个数据集都配了 Python 加载包，装好就能用。
  • 选题看期刊，《分析化学》和《光谱学与光谱分析》都是中文，看得懂，翻目录就能找到能做的事。

遥感影像

非法排污、非法采矿、非法占地、固废倾倒，都会在地表和影像上留下痕迹。Sentinel-2 的影像免费，Google Earth Engine 学生可以用，一台笔记本就够，这个最适合大一。第一步不用写代码，找你家附近一个采砂点或堆场，把 2024 年和 2026 年的影像调出来并排放着看。

影像和处理工具都免费：

  • 影像去 Copernicus Browser 下载，Sentinel-2 不要钱，注册一个学生账号即可。
  • 处理用 Google Earth Engine，Community Tutorials 里有现成脚本，抄下来改参数就能出图。
  • 国内的影像在地理空间数据云（gscloud.cn），Landsat 和一部分国产高分数据都能下。

电子数据

涉网案件、电诈、洗钱，核心证据是流水。从几十万条里找出层级账户、快进快出、集中转入分散转出这类结构，再画成关系图。工具都是免费的，也不需要仪器和场地，一个人就能做：

  • 图数据库用 Neo4j 社区版，配 GraphAcademy 上的免费入门课，几个小时能上手。
  • 画图用 networkx，文档里的例子改一改就够用，几十行代码。
  • 练手数据在 Kaggle，信用卡欺诈那份数据集的结构和真实流水很像。

时间上怎么排

时间上不用排得太满：

  • 开学第一个月，把人工智能导论当回事，同时装好 Python 跑通第一个例子。
  • 第一学期末，能独立走完一次“数据、清洗、模型、结果”的流程，哪怕数据只有一百来条。
  • 寒假，带着这个小流程去找老师，问能不能进组，先从基础工作干起。
  • 大一下，申报校级大创。选题一定要小，就做某一类食品或药品的快检，不要写“AI 赋能食药环侦查体系”这种题目。

进组的邮件不用夸大自己会什么，说三句就行：我大几，绩点多少，我能做文献整理和数据录入这类工作，想长期跟下去。年轻老师缺人手，缺的是可靠的人。

这些不必一次做完，挑一条先做三个月。做不下去换一条也行，但最好先把这三个月做满，做满了才知道是不喜欢，还是没到时候。

有想不通的地方，打电话回来。
