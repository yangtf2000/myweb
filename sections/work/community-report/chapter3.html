第3章 资金与申报

本章讲"怎么报、钱从哪来"，聚焦可操作的程序与渠道。

3.1 申报程序与范围

完整社区（湖南为绿色完整居住社区）创建申报，采用\*\*"省级组织、市级统筹、区县落实、社区实施"\*\*的层级推进机制：

  1. 组织主体：由省级住建部门会同民政部门组织实施，市级统筹、区县落实；
  2. 申报范围：以社区居委会辖区为基本单元，湖南按每市州3—5个社区确定创建试点（其中结合城镇老旧小区改造试点不少于2个）；
  3. 申报材料：创建工作方案、社区现状调查、建设方案、资金测算、实施时序与运营方式；
  4. 申报流程：社区申报 → 区县推荐 → 市级初审 → 省级审定 → 纳入创建名单。

申报要点：申报前必须先开展社区专项体检，摸清设施配套、环境建设、服务治理等问题短板，分清轻重缓急，制定完整社区建设项目清单——"先体检、后申报"是硬前提。

3.2 资金渠道与筹措

资金来源额度/要求用途
中央财政城市更新行动补助（中部城市≤10亿元）公共设施、基础设施、基础类改造
专项债券收益覆盖≥1.2倍，可作资本金重大项目、收益性项目
社会资本引入专业运营、产业投资商业、养老、健身等经营性设施
居民自筹户内改造、加装电梯等居民自主更新、参与共建

投融资模式：构建"中央补助 + 专项债 + 社会资本 + 运营收益"组合模式。中央预算内投资、超长期特别国债对符合条件项目给予支持；地方政府通过专项债券支持，严禁违法违规举债融资；鼓励REITs、资产证券化等市场化工具盘活存量资产，实现资金平衡与滚动发展。

3.3 资金共担模式

完整社区建设的资金难题，核心在于\*\*"政府单打独斗不可持续"。可行的破解思路是建立财政资金、产权单位、专营单位、社会资本、居民自筹五方共担\*\*机制。

参考样板：长沙金科园（全国完整社区样板）

长沙雨花区砂子塘街道金科园社区，结合城镇老旧小区改造创建绿色完整社区，入选国家第一批完整社区样板，总投资约1.28亿元，形成五方共担的"教科书式"结构：

资金方金额（万元）用途占比约
中央及省级财政3735基础类改造，解决功能性问题29%
原产权单位（闲置资产折价）2246盘活闲置资产18%
专营单位558水电气改造4%
社会资本4744养老、健身、商业等社区服务设施37%
居民自筹1470拆违、室内装修、加装电梯11%
案例来源（湖南住建厅官网）：https://zjt.hunan.gov.cn/zjt/ztzl/ljxqgz1/msjyjlu/202406/t20240626_33699918.html

金科园模式的启示：

  1. 财政"四两拨千斤"：3735万财政投入（占29%）撬动总盘子1.28亿，关键在于财政资金先行解决基础类功能性问题，带动多方跟进；
  2. 存量盘活是关键：原产权单位提供2246万闲置资产、社会资本建设养老健身等经营性设施并持续运营盈利（盈利10%反哺社区慈善基金），实现"自我造血"；
  3. 居民共建：1470万居民出资用于拆违、装修、电梯加装，体现"共建共享"；
  4. 机制可持续：物业费0.8元/㎡、缴费率从50%—60%提升至90%，社会资本运营实现长效收益。
