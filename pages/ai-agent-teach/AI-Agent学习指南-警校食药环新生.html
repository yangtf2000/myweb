PART 01

认识 AI Agent：从"聊天机器人"到"数字助手"

在开始一切之前，你需要真正理解 AI Agent 是什么，它和你用过的"AI 聊天"有什么本质区别

🤖 什么是 AI Agent

你可能已经用过 ChatGPT、文心一言或者豆包跟 AI 聊过天——你问一个问题，它回答一个答案。这叫 AI 对话（Chat）。

但 AI Agent（人工智能智能体）不一样。打个比方：

🍳 厨房比喻

AI 对话就像你问厨师"红烧肉怎么做？"，厨师告诉你步骤，但你自己动手做。

AI Agent就像你跟厨师说"帮我做一份红烧肉"，厨师自己走进厨房、找食材、切肉、调味、出锅，最后把菜端到你面前。

用技术语言来说，AI Agent 是一种能够自主感知环境、理解目标、拆解任务、调用工具、执行操作并交付成果的智能系统。它不只是"回答问题"，而是"完成任务"。

AI Agent 的四个核心能力

能力一

🎯 目标理解

你说"帮我准备四级考试"，它能理解这是一个包含词汇、听力、阅读、写作多个子任务的复杂目标，并自动拆解。

能力二

🔧 工具调用

它能使用搜索引擎查资料、读取文件、写代码、运行程序、创建文档——就像人使用各种工具一样。

能力三

🧠 记忆能力

它能记住你之前的对话、偏好和项目上下文，不需要你每次都从头解释。比如记住你是食药环专业的学生。

能力四

🔄 自主迭代

遇到错误它会自己修正，做完一步会自动进入下一步，不需要你一步步盯着指挥。写代码报错了？它自己读错误信息然后修复。

PART 01

AI Agent 与普通 AI 对话的本质区别

理解了这个区别，你就明白为什么大学学习应该用 Agent 而不只是 Chat。

对比维度 普通 AI 对话（Chat） AI Agent
交互方式 一问一答，你问它才答 你给目标，它主动拆解、执行、交付
任务范围 单一问题，文本回答 多步骤复杂任务，跨工具协作
文件操作 无法读写本地文件 能读文件、写代码、创建文档、部署网页
代码执行 只能给你代码片段，你自己复制运行 自己写代码、自己运行、报错自己修
记忆能力 通常只记住当前对话 跨会话记住项目上下文和个人偏好
成果交付 输出文字到聊天框 直接生成文件、文档、网页应用
💡 一句话总结

Chat 是你的"搜索引擎升级版"，Agent 是你的"数字员工"。大学学习需要的是能帮你做事的助手，而不只是说话的助手。

📊 一个具体例子：整理课堂笔记

假设你刚上完一节《食品安全法》的课，手头有一堆零散的课堂记录。看看两种方式的差别：

方式一：用普通 AI 对话

1. 你把笔记复制粘贴到对话框

2. 问"帮我整理一下"

3. AI 输出整理后的文字

4. 你再手动复制到 Word/笔记软件里保存

5. 下次想找某个知识点，还得翻聊天记录

→ 每次都要手动操作，效率低，且无法积累

方式二：用 AI Agent（如 WorkBuddy）

1. 你说"这是我今天的《食品安全法》课堂笔记，帮我整理成结构化的复习资料，保存到我的学习笔记文件夹"

2. Agent 自动：解析内容 → 提取知识点 → 生成结构化文档 → 保存为 Markdown 文件

3. 下次你说"帮我复习食品安全法第三章"，Agent 直接读取之前的笔记文件

4. 期末你说"把所有食药环专业课笔记生成一份复习大纲"，Agent 自动汇总整个学期的文件

→ 一次输入，持续积累，越用越聪明

PART 02

主流 AI Agent 工具盘点

了解了概念，接下来认识你手中可以使用的具体工具

市面上 AI 工具很多，但作为大学新生，你不需要全部尝试。以下是经过筛选的、最适合学生使用的 AI Agent 工具：

日常办公

豆包（字节跳动）

定位：日常办公与生活助手

擅长：文档处理、会议记录、日程管理、翻译、PPT 生成、数据分析。支持语音输入，适合课堂速记。

适合场景：写作业、整理笔记、翻译文献、做汇报 PPT、管理日程

项目开发

WorkBuddy

定位：项目级 AI Agent 开发平台

擅长：多步骤复杂任务、代码开发、文件管理、网页应用部署。支持"项目模式"，能在一个工作区里持续积累成果。

适合场景：开发背单词程序、做学习管理网页、整理学期项目、提交 GitHub

✅ 推荐组合策略

豆包负责日常轻量任务：课堂速记、翻译、做 PPT、写文档、管理日程 —— 随时随地、快速响应。

WorkBuddy负责深度项目任务：开发程序、管理学期项目文件、做研究报告、整理知识体系 —— 沉淀成果、持续迭代。

两者搭配使用：豆包是"速记本"，WorkBuddy 是"工作台"。

PART 03

新生面临的核心挑战与 AI Agent 破局点

挑战一：信息过载，不知从何学起

大一刚入学，面对十几门课程、大量专业术语，很容易迷茫。破局：用 AI Agent 梳理课程知识体系，生成学习路线图，把"不知道学什么"变成"知道每周学什么"。

挑战二：笔记混乱，复习找不到东西

课堂手写笔记、手机拍照、课本标注散落各处，期末找不到重点。破局：用豆包语音速记 + WorkBuddy 文件管理，建立结构化笔记体系。

挑战三：四级备考缺乏规划

不知道怎么安排词汇、听力、阅读的复习节奏。破局：让 AI Agent 根据你的时间制定个性化备考计划，甚至开发专属背单词程序。

挑战四：法律条文背不住

《食品安全法》148 条、《药品管理法》155 条……死记硬背效率极低。破局：用 AI Agent 生成案例化记忆卡片、口诀、思维导图。

挑战五：想学编程但零基础

食药环专业对数据分析、信息化侦查有要求，但没学过编程。破局：用 WorkBuddy 的 AI 辅助编程，从"描述需求"开始，不写一行代码也能做出应用。

挑战六：学习成果无处展示

做了笔记、写了报告、开发了小程序，但没有地方沉淀和展示。破局：用 GitHub 建立个人数字作品集，把学习成果变成可见的资产。

六大学习场景实战

这是本指南的核心部分。每个场景都包含：场景描述 → 传统痛点 → AI Agent 方案 → 具体操作步骤 → Prompt 示例 → 成果产出

📝

场景一：智能笔记系统

把零散的课堂记录变成结构化的知识宝库

📌 场景描述

今天上了《食品安全学》，老师讲了一堆：HACCP 体系、食品添加剂分类、GB 标准编号规则、食物中毒调查流程……你手写了一页纸的潦草笔记，拍了三张 PPT 照片。晚上回到宿舍，看着这些零散信息，不知道怎么整理。

😣 传统方式

打开 Word，把笔记敲一遍，拍照的内容手动描述，最后得到一个混乱的文档。下次复习时翻半天找不到 HACCP 的定义在哪一页。

✨ AI Agent 方案

用豆包语音输入课堂内容（甚至直接读笔记），让 AI 整理成结构化笔记；再用WorkBuddy创建笔记项目，把每节课的笔记保存为文件，形成知识体系。

📋 具体操作步骤

  1. 课堂速记（用豆包）

    下课后立刻打开豆包，用语音输入复述课堂内容。不用管格式，想到什么说什么。豆包会自动把语音转成文字。

  2. 智能整理（用豆包）

    用下面的 Prompt 让豆包帮你整理：

    我是警察学院食药环专业大一学生，刚上完《食品安全学》课。以下是我的课堂速记（语音转文字），请帮我整理成结构化笔记，要求：
    1. 按"知识点-定义-要点-案例"格式组织
    2. 标注重点和可能考点
    3. 食品安全相关的法规条款请标注法律名称和条款号
    4. 生成一份适合期末复习的笔记

    课堂速记内容：[粘贴你的语音转文字内容]

  3. 沉淀到项目（用 WorkBuddy）

    在 WorkBuddy 中创建一个"学习笔记"项目，把整理好的笔记保存为 Markdown 文件，按"课程名/章节号-主题.md"命名。例如：食品安全学/03-HACCP体系.md

  4. 期末汇总复习

    期末时对 WorkBuddy 说：

    读取我的"学习笔记"项目下所有"食品安全学"的笔记文件，帮我生成一份期末复习大纲，按章节列出所有知识点，标注重点和考点，并生成一份自测题（含答案）。

📦 成果产出

结构化笔记文件 期末复习大纲 自测题库

场景二：查资料与文献检索

从海量信息中精准找到你需要的专业资料

📌 场景描述

老师布置了一项作业："分析一起近年来的食品安全犯罪案例，从法律适用和侦查技术两个角度进行分析"。你打开百度搜索"食品安全犯罪案例"，结果出来几万条无关信息，根本找不到有用的。

😣 传统方式

百度搜索 → 翻很多页 → 找到新闻但缺少法律分析 → 再搜法律条文 → 手动拼凑 → 质量低、耗时长。

✨ AI Agent 方案

用 AI Agent 进行多维度检索：先让它帮你筛选典型案例，再针对性检索法律条文和侦查技术资料，最后整合成结构化的分析报告。

📋 具体操作步骤

  1. 第一步：明确检索方向

    先让 AI Agent 帮你确定检索策略：

    我是食药环专业学生，需要完成一份食品安全犯罪案例分析作业。请帮我：
    1. 推荐 3-5 起近年来（2020年后）有代表性的食品安全犯罪案例
    2. 每个案例标注：案件名称、发生地、涉及食品类型、犯罪手段、适用法律
    3. 帮我分析哪个案例最适合从"法律适用"和"侦查技术"两个角度展开分析
    4. 给出检索关键词建议

  2. 第二步：深入检索法律条文

    选定案例后，针对性检索相关法律：

    关于"生产、销售不符合安全标准的食品罪"（《刑法》第143条），请帮我整理：
    1. 法条原文及构成要件
    2. 立案追诉标准
    3. 与《食品安全法》的衔接关系
    4. 典型判决中的量刑参考
    请标注信息来源，确保法律条文准确。

  3. 第三步：整理成报告

    用 WorkBuddy 将检索结果整理为结构化报告：

    把以上检索到的案例信息、法律条文和分析整合成一份完整的案例分析报告，格式要求：
    1. 案例概述（案件背景、基本事实）
    2. 法律适用分析（涉嫌罪名、构成要件分析、量刑分析）
    3. 侦查技术分析（现场勘查要点、物证采集、检验鉴定）
    4. 思考与启示
    输出为 Markdown 格式，保存到我的"课程作业"项目下。

⚠️ 重要提示：AI 检索的法律条文需要核实

AI 可能生成过时或不准确的法律条文。关键法律条文务必在北大法宝、中国法律法规数据库等权威平台核实原文。AI 是帮你找方向和整理框架，法律准确性以权威来源为准。

📦 成果产出

案例分析报告 法律条文汇编 检索关键词库

场景三：学习计划制定与四级备考

让 AI 帮你把"过四级"这个大目标拆解成每天的实际行动

📌 场景描述

大一第一学期，学校要求大二上学期之前通过英语四级。你的英语基础一般（高考英语 110 分左右），词汇量大约 3500，离四级要求的 4500 词还差 1000。同时还要应付专业课和警体训练，时间很紧。

✨ AI Agent 方案

分三步走：能力诊断 → 智能排期 → 动态调整。让 AI Agent 根据你的实际水平和可用时间，制定一份可执行、可调整的备考计划。

📋 第一步：能力诊断与计划制定

我是警察学院食药环专业大一新生，需要备考英语四级（CET-4）。

我的情况：
- 高考英语 110 分（满分150），基础中等
- 词汇量约 3500，听力较弱
- 每天可用英语学习时间：工作日 1.5 小时，周末 3 小时
- 警校有早操和晚自习，时间相对固定
- 距考试还有 120 天

请帮我制定一份 120 天四级备考计划，要求：
1. 分为"基础积累期""专项突破期""模拟冲刺期"三个阶段
2. 每个阶段有明确的目标和每日任务
3. 考虑到警校作息，给出具体到每天的时间安排
4. 词汇、听力、阅读、写作、翻译五项均衡安排
5. 每两周安排一次模拟测试节点

📋 第二步：词汇记忆策略

四级词汇是基础中的基础。让 AI Agent 帮你制定科学的背词策略：

基于艾宾浩斯遗忘曲线，帮我制定一个四级核心词汇的记忆计划：
1. 每天新学 40 个单词，复习前一天和前几天的
2. 按"高频词→中频词→低频词"的优先级排列

  const intervals = [1, 2, 4, 7, 15, 30];
  const reviewCount = word.reviewCount || 0;

  if (reviewCount < intervals.length) {

  return null; // 已掌握，无需再复习

四学期成长路线图

从大一到大二，系统化地掌握 AI Agent 的使用

📍 大一上学期 · 入门期

目标：建立 AI Agent 使用习惯

  • 注册并开始使用豆包，每天用语音记录课堂笔记
  • 让 AI 制定四级备考计划，开始系统背单词
  • 注册 GitHub 账号，学会基本的 clone/commit/push
  • 用 WorkBuddy 整理第一学期的课程笔记

📍 大一下学期 · 进阶期

目标：开始用 AI Agent 做项目

  • 参加四级考试（目标一次性通过）
  • 用 WorkBuddy 开发背单词网页程序并提交到 GitHub
  • 用 AI Agent 辅助完成第一份案例分析报告
  • 建立结构化的学习笔记体系（按课程分文件夹）

📍 大二上学期 · 深度期

目标：用 AI Agent 做学术研究

  • 用 AI Agent 辅助完成学年论文（从选题到成稿）
  • 开发第二个项目：如法律条文查询工具、实验数据可视化工具
  • 在 GitHub 上积累 3-5 个项目，写好 README
  • 开始学习看懂 AI 生成的代码，逐步理解编程逻辑

📍 大二下学期 · 输出期

目标：从使用者变成创造者

  • 能独立用 AI Agent 完成复杂项目（如食品安全数据分析平台）
  • GitHub 主页有完整的作品集，包含项目说明和截图
  • 能教同学使用 AI Agent（教是最好的学）
  • 开始探索 AI 在食药环侦查领域的专业应用
