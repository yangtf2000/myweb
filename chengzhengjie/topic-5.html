CHAPTER SUMMARY

本章整合0601版及各规划项目，统一六大类分类口径，形成40个完整项目库（总投资25.25亿元），较0601版增加11个项目9.15亿元，明确投资构成（工程费80%+其他10%+预备费10%）和前10大重点项目（12.3亿占48.7%），安排三期实施时序（近期11.28亿+中期12.50亿+远期1.97亿），设计五个项目捆绑组实现资金平衡。

→ 对片区策划的核心建议

① 六大类项目分类（A历史保护/B闲置盘活/C危房/D老旧小区/E街区更新/F基础设施）作为项目库框架；

② 三期实施时序作为实施计划，前10大重点项目作为近期优先推进清单；

③ 五个项目捆绑组（经营性反哺公益性）作为资金平衡策略，40个项目完整清单作为附表。

INTRODUCTION

引言：项目库是实施的抓手

项目库是片区更新实施的抓手，也是投资估算和资金筹措的基础。0601汇报版已形成29个项目、总投资16.10亿元的项目库，但与保护规划、更新规划、江湾规划等其他规划中的项目存在口径不一、重复遗漏等问题。本专题系统对比各规划中的项目，统一分类口径，识别重复和遗漏，补充新增项目，形成六大类共40个完整项目库，并进行投资估算和分期时序安排。

2.5历史街区核心区新增策划项目建议

现有项目库中，历史街区核心区的项目以文保修缮和闲置资产盘活为主，但对于"让历史街区立起来"所需的基础环境改造、节点打造、旅游配套等覆盖不足。为实现第五章提出的定位和愿景，在现有项目之外，建议新增以下项目，按政府投入和社会投资两类区分。具体数量和规模需在下一阶段深化设计后确定，此处仅提出项目方向和内容建议。

第一类：政府投入项目（基础设施与公共环境）

①传统街巷改造提质工程

范围：城正街主街及板石巷、泗洲庵巷、学坪路街等七巷。
内容：路面青石板/麻石铺装恢复；两侧建筑立面风貌整治（不搞大拆大建，以修缮、清洗、粉刷、更换门窗为主）；旅游设施（导视系统、标识标牌、休憩座椅、环卫设施）；水电基础设施（给排水、电力通信下地、消防设施）；夜景照明系统。
优先级：最高，是历史街区"立起来"的基础。

②关键节点打造工程

范围：关圣殿—文庙—江西会馆沿线核心节点。
内容：游客服务中心（含讲解、休息、卫生间、文创售卖）；广场节点（城里头广场、文庙广场、关圣殿前广场的景观提升）；口袋公园与绿化空间（利用拆违空地和闲置边角地）；文化展示节点（古城门遗址标识、古码头纪念标识、历史街巷地刻）。
优先级：高，直接影响游客体验和街区形象。

③停车场与交通配套

范围：历史街区外围及核心区边缘。
内容：外围公共停车场（利用闲置土地改造，建议2-3处）；核心区步行化改造（机动车限行或限时通行）；非机动车停放区；旅游大巴上下客点；智慧停车引导系统。
优先级：高，解决"进不来、停不下"的瓶颈问题。

④公共建筑基础性改造

范围：核心区内闲置公房、厂房等政府持有资产。
内容：仅包括建筑物基础性改造（结构加固、屋面防水、外墙修缮、水电接入、消防改造）和场地平整完善，不包括内部装修和业态导入。改造后作为可招商资产移交运营方。
优先级：中高，为社会资本进入创造条件。

第二类：鼓励社会投资项目（经营性业态导入）

⑤闲置资产经营性改造

范围：核心区内已完成基础改造的闲置厂房、办公楼、仓库等。
内容：内部装修、业态导入和运营，包括主题酒店、精品民宿、文创办公、非遗工坊、特色餐饮、文化展示空间等。政府以"以修代租""租金减免""联营分成"等方式引导社会资本投入。
实施方式：特许经营/租赁/合作运营。

⑥沿街商业业态提升

范围：城正街主街及重点巷弄两侧。
内容：老字号复兴、特色小店引入、文创零售、非遗体验店、主题餐饮、茶馆咖啡馆等。政府负责统一规划和业态引导，社会资本负责投资和运营。
实施方式：招商引导+主理人培育+运营补贴。

⑦文化体验与文旅产品

范围：核心区文保单位及公共空间。
内容：沉浸式演艺、非遗体验课程、研学旅行产品、城总文化主题展陈、夜间经济项目（夜市、灯光秀、文化活动）等。
实施方式：政府提供场地和政策支持，专业运营团队投资运营。

⑧文旅旅居配套

范围：核心区及建控地带内适合改造的建筑。
内容：精品酒店、主题民宿、青年旅舍等住宿业态，以及配套的餐饮、会议、休闲设施。
实施方式：社会资本投资为主，政府给予风貌管控指导和政策支持。

新增项目实施建议

第一，政府投入优先序：传统街巷改造提质 → 关键节点打造 → 停车场与交通配套 → 公共建筑基础改造。前两项是历史街区"立起来"的前提，必须政府主导、优先实施。

第二，社会资本引入节奏：待政府完成基础环境改造和公共建筑基础性改造后，再分批引入社会资本进行经营性改造和业态导入，避免"社会资本还没进来，基础环境没做好"的尴尬。

第三，与现有项目库的关系：上述新增项目中，部分内容可能与现有项目库中的"街巷格局保护与提升""城正街主街商业提升""公共停车场"等项目有重叠，建议在下一阶段合并同类项、明确边界，避免重复投资。

分期原则

①民生优先（危房、老旧小区、基础设施补短板）②示范引领（先实施重点示范项目形成效应）③先易后难（产权清晰、协调难度小的先做）④产业跟进（保护和民生项目后导入产业）⑤运营前置（产业项目建设阶段就引入运营方）

CHAPTER 05 · PROJECT BUNDLING

五、项目捆绑与统筹实施

由于部分公益性项目投资大、回报低，需要与经营性项目捆绑实施，实现资金平衡。以经营性项目收益反哺公益性项目投入，同一区域或同一主题的项目捆绑，由同一实施主体统筹。

捆绑组一：会馆文化主题
经营性：古城主题酒店 + 综合商业
公益性：关圣殿修缮 + 江西会馆修复
逻辑：酒店商业收益反哺文保
捆绑组二：文创产业主题
经营性：城总记忆场 + 文创园区
公益性：历史建筑修缮 + 街巷提升
逻辑：文创产业收益反哺历史建筑保护
捆绑组三：民生改善主题
经营性：闲置土地开发（部分商业）
公益性：老旧小区改造 + 基础设施
逻辑：土地开发收益反哺民生投入
捆绑组四：街区整治主题
经营性：大同世界综合商业
公益性：建设北路街区更新 + 停车场
逻辑：商业收益反哺街区整治
捆绑组五：文旅研学主题
经营性：民宿集群 + 特色餐饮
公益性：文庙修缮 + 研学基地
逻辑：文旅收益反哺文化保护

5.1实施主体安排

项目类型实施主体合作模式
文保修缮、历史建筑保护文旅广体局 + 平台公司政府主导，专业团队实施
老旧小区改造、危房改造住建局 + 区政府 + 平台公司政府主导，居民参与
闲置资产盘活平台公司 + 专业运营商政企合作，市场化运营
产业导入项目平台公司 + 社会资本PPP、特许经营、租赁
基础设施住建局 + 城管局 + 平台公司政府投资，专业实施
公共服务设施各主管部门 + 区政府政府投资，专业运营

上述25.25亿元投资和40个项目为基于现有各规划成果的初步估算，尚未覆盖全部实施需求。项目库的价值在于提供一个可讨论、可调整的框架，后续需结合详细勘察、设计深化和资金筹措情况动态修订。特别是历史街区核心区的风貌整治、基础设施提升等项目，目前估算偏粗，实际投入可能高于现有测算。

RECOMMENDATION FOR PLANNING

本章对片区策划的建议

对应策划模版板块：04更新项目（项目库+投资+时序）

推荐直接采用：①六大类项目分类（A历史保护/B闲置盘活/C危房/D老旧小区/E街区更新/F基础设施）作为项目库分类框架；②三期实施时序（近期2026-2028年11.28亿+中期2029-2030年12.50亿+远期2031-2035年1.97亿）作为实施计划；③前10大重点项目（12.3亿占48.7%）作为近期重点推进项目清单；④五个项目捆绑组（经营性反哺公益性）作为资金平衡策略。

建议转化使用：①40个项目的完整清单建议作为附表，策划正文用分类统计和重点项目介绍呈现，不逐个罗列；②投资估算的详细构成（工程费80%+其他10%+预备费10%）建议简化为总投资+分类投资+分期投资三个层级；③与0601版的对比分析（29个16.1亿→40个25.25亿）建议在策划方案中说明"项目库优化"的逻辑，不做详细对比表。

不建议纳入策划正文：每个项目的详细工程量清单、单价分析、具体技术方案。这些在后续可行性研究和初步设计阶段深化，策划方案应聚焦"项目构成+投资规模+实施时序"的宏观框架。
